# human-desires

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

An application for reflecting on human desires through self-assessment and visualization.

## Demo

[Desire Reflection App](https://code4fukui.github.io/human-desires/)

## Features

-   **Assess Desires**: Evaluate over 80 human desires, marking each as "Lacking" (unfulfilled) or "Sufficient" (fulfilled).
-   **Visualize Results**: A "Desire Map" radar chart is generated in real-time, showing the proportion of unfulfilled desires across categories like Health, Money, and Work.
-   **Share Your Map**: Once complete, a unique URL and QR code are generated to save or share your personal desire map.
-   **Easy Navigation**: A "Jump to Unanswered" button lets you quickly find any questions you've skipped.
-   **Reset**: Start over at any time by clearing all answers with a single click.

## How to Use

1.  Open the **[Desire Reflection App](https://code4fukui.github.io/human-desires/)**.
2.  For each desire, select **"Lacking" (はい（不足）)** if it's an unmet need, or **"Sufficient" (いいえ（十分）)** if it is fulfilled.
3.  Your "Desire Map" radar chart will update automatically at the bottom of the page.
4.  After answering all questions, use the generated QR code or copy the URL to save or share your results.
