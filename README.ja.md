# human-desires

自己評価と可視化を通じて、人間の欲求をふりかえるためのアプリケーションです。

## デモ

[欲求ふりかえりアプリ](https://code4fukui.github.io/human-desires/)

## 機能

- **欲求の評価**: 80以上の人間の欲求について、「はい（不足）」または「いいえ（十分）」のいずれかで評価します。
- **結果の可視化**: 「欲求マップ」のレーダーチャートがリアルタイムで生成され、健康、お金、仕事などのカテゴリごとに満たされていない欲求の割合が表示されます。
- **マップの共有**: 完了後、固有のURLとQRコードが生成され、個人の欲求マップを保存または共有できます。
- **簡単なナビゲーション**: 「未回答へジャンプ」ボタンで、スキップした質問をすぐに見つけることができます。
- **リセット**: いつでもクリック1つですべての回答をクリアし、最初からやり直すことができます。

## 使い方

1. **[欲求ふりかえりアプリ](https://code4fukui.github.io/human-desires/)** を開きます。
2. 各欲求について、満たされていない場合は **「はい（不足）」** を、満たされている場合は **「いいえ（十分）」** を選択します。
3. ページ下部の「欲求マップ」レーダーチャートが自動的に更新されます。
4. すべての質問に回答した後、生成されたQRコードを使用するかURLをコピーして、結果を保存または共有します。

## データと帰属

- **欲求リスト**: 本アプリケーションは [human-desires.csv](human-desires.csv) のデータを使用しています。
- **データソース**: 欲求リストは、おもちゃクリエーターの高橋晋平氏による [人間の「欲求・快楽リスト完全版」](https://note.com/simpeiidea/n/nd8a8b0d5b5b8) に基づいています。
- **ベースアプリケーション**: このアプリは [qr-survey](https://github.com/code4fukui/qr-survey/) のフォークです。
